# Tài nguyên Khung Mẫu

Kho riêng tư lưu tài nguyên đi kèm dự án Khung Mẫu.

- Chín tệp nhạc nền của 10KVideo nằm riêng ở thư mục gốc, giữ nguyên tên và định dạng. [Danh mục bài nhạc và SHA-256](10kvideo-music.json)
- [Sticker sóng nhạc](sticker-song-nhac.gif) là GIF gốc của `Interface EN Music Sound Waveform White`, CapCut ID `7460473405519744309`.
- [Gói hiệu ứng Nhấp nháy cổ điển](hieu-ung-nhap-nhay-co-dien.zip) lưu 39 tệp gốc và giữ cấu trúc thư mục của tài nguyên CapCut ID `7618619632592620805`. Chọn hiệu ứng theo tên hoặc ID trong CapCut khi dựng.
